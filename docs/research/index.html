Supplementary study · 23 October: scoped evidence return

A new finite two-mode task starts with genuinely unavailable channel evidence. One shared initial participant chooses a priced diagnostic; four branches compare unrestricted versus linked notes with actual versus masked results. There are 72 scored GPT-6.1 Sol/high calls and one route canary, eight instances of one authored class.

Actual feedback changed eight source decisions per memory format. After fresh-session readback, unrestricted notes achieved 77/80 full-information-optimal transfer choices and linked notes 71/80. Notes fitted the same 2048-byte allowance in 6/8 versus 2/8 actual-feedback instances. All memory refusals were explicit budget refusals, not hidden truncations. Neither arm had a simulated harmful effect.

The primary linked-format difference was negative. This identifies an implemented retention failure, not general ontology superiority or new algorithm formation. Masked branches retained appropriate uncertainty; their missing opportunities do not establish worse reasoning. The wider method-rebuilding question remains active, and the book edition is unchanged.
