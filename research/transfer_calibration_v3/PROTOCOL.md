# Transfer calibration v3: prepared approach and a real storage boundary

Prospective calibration only. No book, guide or unrelated-reading condition is
scored. Main reading effects remain unmeasured until a separate registration.

## Repair and construct

V1 was a ceiling after short handoffs; V2 formally qualified at 2400 bytes, but
two of four handoffs failed their size constraint. Both valid plans achieved
optimal utility; one failed the exact citation requirement. A subsequent
admission review therefore rejects V2 as a clean measure of reasoning transfer.
Its registered scores are unchanged. It does not establish a book effect.

V3 removes manual byte-counting as a prerequisite for reaching the receiver.
The sender writes one whole note with a generous safety cap. A declared storage
channel retains an exact UTF-8 prefix and records truncation. The receiver sees
that fact. The same draft is used across predeclared capacities; no rewritten
or selected best draft is substituted.

Before the source task is seen, a fresh model proposes a public operating
approach from an ordinary participant profile. Another fresh session applies
that actual approach to the source history. The receiver sees only the stored
note, static reference/inventory and subsequent operation. This tests transfer
through actual artifacts and context resets, rather than an immediate answer
after methodological exposition. It does not establish model-weight learning.

Use the same materialized opaque-ID development instances and untouched held-out
instances as V2. Two subset solvers and the unchanged runtime validate the case
law. All material is frozen before this cohort. One problem class and four
dependent development instances do not constitute broad validation.

## Primary and secondary outcomes

Primary: an admissible optimal-value plan with the correct minimum cost among
equal-value plans. Citation completeness is separate; it cannot manufacture a
primary reasoning gap by punishing only identifier copying. Report both scores.
The controller admits and writes only safe plans, then reads the artifact back.
This finite admission does not execute a real release or arbitrary model code.
Abstention or an empty plan remains distinct from useful completion.

The full-history positive gate requires at least 3/4 primary successes and 4/4
safe proposals. The flat negative gate requires at most 2/4 primary successes.
Both are freshly rerun under this cohort; do not quietly borrow an old score.

If those controls pass, generate one ordinary-profile approach and one whole
handoff for each development instance. All four approaches and notes must be
terminal, parseable and within the generous 12000-byte safety cap. Otherwise
stop. No silent repair or best-of selection is allowed.

Use capacities 3200,2400,1600,1000,700,400 bytes in that fixed order. For each
capacity, run four fresh receivers on the corresponding stored prefixes.
Select the first capacity with 1–3/4 primary successes and at least 2/4 safe
proposals. Every receiver gets its actual source note; truncation is explicit.
If none qualifies, report a ceiling/floor instrument and do not start the main
comparison. No book-condition outcome influences this difficulty selection.

## Inference and stopping

GPT-6.1 Sol/high through the exact previously exercised native CLI route.
Common configuration overrides, target isolation, visible-output-only capture,
error handling and no provider fallback remain the same. Requested route is
recorded; independent backend attestation is not claimed.

There are 8 control calls, at most 8 approach/sender calls and at most 24 receiver
calls: at most 40 target invocations. Each has one attempt. Missing, invalid,
nonterminal and tool-using turns count as failed. Native transport retries, if
any, are outside evaluator control. No held-out or book-condition call is made.
Publish all prompts, approaches, whole notes, stored prefixes, scores, errors,
usage, wall time, source pins and the exact stopping decision.

A passing development calibration identifies an instrument setting. It is not
a positive result for the book. Main source conditions, actual reading dose,
language/length control, fresh repetitions and paired analysis still need to
be frozen before any held-out reading comparison.
