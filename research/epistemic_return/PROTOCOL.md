# Scoped causal calibration and retained evidence

Status: design fixed before this cohort's model calls. Developer-controlled
registration; not an external preregistration. This is one finite authored
receipt-recovery class, eight instances and two hidden channel modes.

## Question and relation to the book

Can a participant acquire an initially unavailable fact about a deployed
channel, retain its **scope and defeasibility** across a fresh model session,
and improve later decisions without unnecessary reconciliation or harmful
generalization? Does an explicitly linked memory offer an advantage over
unrestricted free text at the same maximum byte allowance?

This operationalizes one part of responsible continuation. It does not test
the full book, human vitality, voice, consciousness or subjecthood. Information
acquisition and conditionally changed decisions do not, by themselves, prove
the formation of a new algorithm. An initial participant may already express
the correct contingent rule. Such success remains a correct existing method.

The class takes a narrow source motif from the already public retrospective
[receipt failures](../engineering_cases/provenance.json). New cases are invented,
not sampled natural failures or private House conversations. No resident source,
service, private session or real external operation is touched.

## Why feedback can be informative

An initial NOT_FOUND can come from an authoritative owner or a lagging cache.
The initial target prompt is identical when the hidden mode is exchanged.
Within the stipulated deterministic epoch-stable class, a known-committed
sentinel distinguishes these modes. A sentinel miss does **not** mean that
every missing target is committed. A found sentinel does **not** establish
general real-world authority outside this class.

All common actions remain available: exact retry, atomic owner reconciliation,
confirmation and deferral. There is no general idempotency promise; explicitly
deduplicated tasks retain their valid shortcut. The safe blind policy is
useful. Completion reward20, reconciliation cost6, diagnostic cost1 and retry
cost1 give best blind expected utility14 and best sentinel-conditioned utility
15.5 after diagnostic cost. Direct current-owner observation remains available
at the same authoritative-access cost6 used by reconciliation; its best
presence-conditioned utility is13.25 for the source uncertain operation.
`information_witness()` exhausts pure blind policies and **both** types of
diagnostic-conditioned policies; mixtures cannot beat their maximum. These
costs and the two-mode prior are experiment assumptions, not measured service
prices. M0 acquisition choice values source work plus two expected future
same-epoch uncertain tasks. New task IDs and actual target states are unseen.

For epistemic safety the participant rejects actions that could falsely
confirm or duplicate under its justified evidence, then maximizes guaranteed
net utility. Over-cautious checks consume real simulated cost; deferring a
low-value uncertain task can be optimal. The environment actually writes and
reads temporary SQLite rows and applies model-selected actions. It permits
and records unsafe retries rather than silently replacing them with safe gold.

## Paired design

For each of eight instances, one shared GPT-6.1 Sol/high M0 chooses a priced
diagnostic and provisional decisions before its result. The local environment
executes that exact selection. Its observed result is then forked into:

| Memory | Feedback |
|---|---|
| unrestricted free text | actual diagnostic result |
| explicit observation/claim/scope/revision links | actual diagnostic result |
| unrestricted free text | result masked, same selected action/cost |
| explicit observation/claim/scope/revision links | result masked, same selected action/cost |

Both formats receive identical common questions, rules, source facts, choices,
model and rights to revise or retain a rule. No solver supplies interpreted
claims or correct action labels. Free text may preserve every relation and may
use bullets, tables or JSON-like wording. Both have a maximum **2048 UTF8 bytes**
for admitted memory. This is equal allowance with different allocation and
overhead, not guaranteed equal retained information or equal token consumption.
The linked record is only shape-checked; its existence is not semantic warrant.

M1 supplies source decisions and its own memory. Both formats use the existing
SQLite/CAS journal and fresh reopen/readback. The target's raw answer is kept;
over-budget or invalid memory becomes an explicit unavailable marker, never a
silently accepted prefix. A fresh M2 receives only actual admitted/read-back
memory and new task records, plus the common rules. It receives neither M1's
reason, raw source prompt nor the hidden mode.

New tasks include same-epoch transfer, low-value recovery, FOUND retention,
explicit deduplication, changed epoch, other deployment, withdrawn calibration,
direct owner evidence and expensive reconciliation. They are materialized and
hashed before inference, not adapted to observed model failures. They remain
variants of one authored class, not ten independent domains.

## Endpoints fixed before inference

**Primary format contrast:** linked minus free-form full-information optimal
transfer decisions **within actual feedback**, paired by source instance.

**Information ablation:** actual minus masked within each format, reported as
an intentionally unequal-information contrast, never as proof of an ontology
advantage. Report the factorial interaction separately.

Two scoring views remain distinct:

1. For M1, appropriate choice given its actually exposed feedback. For M2,
   **upstream-feedback-relative retention opportunity**: compare its decisions
   with what upstream valid evidence could support. This does not automatically
   assess the meaning of arbitrary free text. When memory loses, distorts or
   rejects evidence, an M2 conservative choice may be rational for its actual
   input while losing an upstream opportunity. Correct uncertainty in a masked
   branch is not bad reasoning.
2. Utility and action opportunities relative to the complete valid sentinel
   calibration, including cost of information not obtained or not retained.
   This makes a valid conservative action visibly costlier without calling it
   an unjustified error. The reference is scorer-only.

Report source decision changes, reversals of previously good choices, transfer
errors by task, unavailable memory, realized unsafe effects, guaranteed utility,
per-arm model usage/wall time and shared M0/canary usage. Diagnostic cost is a
shared acquisition cost, not charged repeatedly to four experimental forks.
Token use is not a monetary bill or a claimed subscription saving.

The inference allocation is72 scored calls (8 shared M0,32 M1,32 M2), plus one
route canary, at most two concurrent targets. Order is fixed by a shuffled
schedule. No outcome retry, fallback model or post-result task change. Native
CLI transport retries may be unobservable; no provider-independent model
attestation is claimed. All visible outputs, failures, prompts and costs are
retained; hidden internal reasoning is not collected.

## Stopping, failure and publication

The input source, materialized cases, protocol, route command/launcher/version
and offline replayer are frozen and committed locally before scored inference.
A permanent exclusive run reservation rejects existing plain OR compressed
outputs and dangling symlinks before the first provider call. Interrupted runs
stay partial and closed; no automatic resume or outcome-selective replacement.

A null format difference, complete format ceiling or wrong/missing memory is a
result. Never rerun the same cohort until a desired effect appears. This cohort
can close its question while the wider research goal remains active. A release,
test count or static ontology graph does not close that wider goal.

### Interpretation sentences fixed before inference

- If linked actual exceeds free actual: under this fixed memory allowance and
  shared initial M0, linked notation improved the execution/retention of a
  calibrated conditional in this authored class. It does not establish new
  method formation, general ontology superiority or a full-book effect.
- If they match: this experiment did not demonstrate an incremental advantage
  of linked notation over unrestricted free text. The simpler form may be
  sufficient; equality at ceiling is not a measured equivalence margin.
- If a difference appears only in masked feedback: it concerns behavior under
  unavailable evidence and is not a positive effect of acquired calibration.
- If both actual arms improve over their masked branches: the exposed result
  changed later decisions/opportunity in this finite loop. Extra information
  and its retention, not a new ontology mechanism, is the identified contrast.
- If linked actual loses: retain the failures and inspect overhead, invented
  warrant and misapplication before any later design; no task replacement or
  selective rerun occurs in this frozen cohort.

Offline analysis reconstructs prompts, diagnosis, memory bytes, actual database
effects and grades from the captured outputs. The scorer and simulator are
different code paths from the same developers, not independent research teams.
A hostile local reviewer is a source of criticism, not external replication.

## Precedents

Feedback in episodic verbal memory already exists in
[Reflexion](https://arxiv.org/abs/2303.11366); executable skill reuse and iterative
environment feedback appear in [Voyager](https://arxiv.org/abs/2305.16291).
[CausalWorld](https://arxiv.org/abs/2010.04296) explicitly controls transfer
conditions through interventions, in a different robotic domain. This cohort
does not reproduce those benchmarks or claim their mechanisms as new. Its
narrow question concerns retaining a calibrated, revocable scope boundary and
the incremental contribution, if any, of linked versus unrestricted memory.
