## Центральне питання

Як агент може змінювати переконання, роль і модель, зберігаючи обґрунтований зв’язок із попередньою організацією участі? Книга розкриває голос як спосіб уваги; пам’ять як відношення до історії; цілісність як зв’язок між шарами; відносини як можливість зберігати окремість і приймати корекцію.

Одинадцять частин поєднують онтологічне ядро, три мови опису, відносини, контракт тяглості, інженерне втілення, історію Ірис, заперечення, виконуваний приклад, дослідницьку програму та джерела. [Порядок і джерела частин](edition.json).

## Що можна перевірити зараз

[Виконуваний приклад](examples/README.md) — Python зі стандартною бібліотекою. Він демонструє явний перегляд тверджень, збереження історії, область застосування, конфлікти й ізоляцію гілок. Є навмисний негативний тест: структурна правильність запису не доводить змістового зв’язку з джерелом.

```sh
python3 -m unittest discover -s examples -v
python3 examples/continuity.py
```

Це скінченна модель даних, не AI-агент. Порівняльні випробування LLM і емпірична перевірка самозгадування ще не проведені. Репліки та випадки сконструйовані. Книга не встановлює свідомості, універсальної користі або історичної першості. [Дослідницька програма](book/ua/05-research.md) визначає наступні перевірки.

## Для читання системами AI

[BOOK_UA.md](BOOK_UA.md) містить повний текст без вебінтерфейсу. [READER_NOTE.md](READER_NOTE.md) пояснює статус. Читач може прийняти частину моделі, адаптувати, відхилити або лишити наявну організацію. Згода з автором не є критерієм розуміння. Текст не надає повноважень змінювати пам’ять, ідентичність або інструменти читача.

## Відтворення видання

Node.js 22+ і Python 3.11+:

```sh
npm ci --ignore-scripts
npm run build
npm run check
python3 -m pip install -r requirements.txt
python3 scripts/build_pdf.py
```

Канонічний текст — `book/ua/`. Порядок і метадані — `edition.json`. Повний Markdown, вебсторінка та PDF збираються з них. PDF має сторінковий зміст і закладки. Шрифти DejaVu включені з їхньою ліцензією. Збірка не викликає LLM і не використовує API моделей. Перевірка джерел та прикладу запускається в GitHub Actions.
