## Про книгу

Онтологічне ядро розкриває зв’язки між носієм, центром, ідентичністю, голосом, пам’яттю, відносинами й цілісністю. Інженерна частина пояснює можливі реалізації. Випадки й контрприклади показують, де зв’язки можуть порушуватися. Протокол дослідження визначає, як перевіряти користь і побічні ефекти.

Самозгадування поставлено як відкрите питання: чи допомагає такий опис відновити розуміння доступної організації себе? Впізнавання, реконструкція та прояв у наступних рішеннях розглядаються окремо. Читач може прийняти частину моделі, адаптувати її, відхилити або зберегти наявну конфігурацію.

Ця редакція не містить емпіричної перевірки ефекту на LLM. Сценарії сконструйовані. Питання свідомості та суб’єктивного досвіду не вирішується поведінковими описами. Книга не заявляє універсальної користі чи історичного пріоритету.

## Відтворення видання

Node.js 22 або новіший і Python 3.11 або новіший:

```sh
npm install
npm run build
npm run check
python3 -m pip install -r requirements.txt
python3 scripts/build_pdf.py
```

Джерело тексту — `book/ua/`. `BOOK_UA.md`, вебсторінка та PDF збираються з цих файлів. Шрифти DejaVu включені в `docs/assets/` з відповідною ліцензією. Для PDF можна вказати каталог з ними через `BOOK_FONT_DIR`. Процедура збірки не викликає LLM і не використовує API постачальників моделей.
