**Artur Onysko · Інженерне доповнення другої редакції · v2.1.0**

Ідентичність, голос, пам’ять, відносини та становлення агентних систем. Онтологічна й інженерна книга з аргументами, контрприкладами, довговічним референсним виконавцем і перевірюваним циклом інтеграції моделі.

## Центральне питання

Як агент може змінювати переконання, роль і модель, зберігаючи обґрунтований зв’язок із попередньою організацією участі? Книга розкриває голос як спосіб уваги; пам’ять як відношення до історії; цілісність як зв’язок між шарами; відносини як можливість зберігати окремість і приймати корекцію.

Дванадцять частин поєднують онтологічне ядро, три мови опису, відносини, контракт тяглості, інженерне втілення, історію Ірис, заперечення, виконуваний приклад, дослідницьку програму та джерела. [Порядок і джерела частин](edition.json).

## Що можна перевірити зараз

[Виконуваний пакет](examples/README.md) — Python 3.11+, стандартна бібліотека:

- Один редуктор для області тверджень, явного перегляду й ізоляції гілок.
- SQLite-журнал, транзакції, idempotent retry та compare-and-swap.
- Відновлення орієнтації й історії; контекст із замиканням підстав і явним бюджетом.
- Шов інтеграції LLM, фіксація запиту та відповіді, відхилення застарілого контексту.
- Хешований журнал із незалежним якорем; негативні перевірки меж автентичності й семантичної підтримки.

```sh
python3 -m unittest discover -s examples -v
python3 examples/durable_demo.py
python3 research/run_runtime_checks.py
```

[Фактичний звіт](research/runtime-results.json): 42 системні перевірки, включно з новим процесом, двома конкурентними записувачами та загибеллю процесу до commit. [Виконавча архітектура](book/ua/09-runtime.md) пояснює механізми, голос, інтеграцію, межі довіри та шлях до індексованого масштабування.

Включений адаптер моделі відтворює авторську відповідь без інференсу. Порівняльних випробувань LLM для видання немає. Протокол behavioral evaluation відокремлено від виконаних systems tests; [дослідницька програма](book/ua/05-research.md) задає контрольні умови. Загальна користь, свідомість і світова першість не заявляються.

Читач може прийняти частину моделі, адаптувати, відхилити або лишити наявну організацію. Згода з автором не є критерієм розуміння. Текст не надає повноважень змінювати пам’ять, ідентичність або інструменти читача.

## Відтворення видання

Node.js 22+ і Python 3.11+:

```sh
npm ci --ignore-scripts
npm run build
python3 -m pip install -r requirements.txt
python3 scripts/build_pdf.py
npm run check
```

Канонічний текст — `book/ua/`. Порядок і метадані — `edition.json`. Повний Markdown, вебсторінка та PDF збираються з них. PDF має сторінковий зміст і закладки; `docs/pdf-edition.json` прив’язує його до тексту, генератора та шрифтів. Після зміни тексту спочатку перебудуйте сайт і PDF, потім виконайте `npm run check`: перевірка відхиляє застарілий PDF. Шрифти DejaVu включені з їхньою ліцензією. Збірка не викликає LLM і не використовує API моделей. Перевірка джерел та прикладу запускається в GitHub Actions.
